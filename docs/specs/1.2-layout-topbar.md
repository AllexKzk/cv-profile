# 1.2. Layout и TopBar

**Статус:** review
**Зависит от:** 1.1
**Ветка:** `step/1.2-layout-topbar`

## Цель
Постоянный каркас страницы: сверху панель с контактами слева и переключателями темы и языка
справа, под ней — область контента, где в фазе 2 будет чат. После шага временная демо-страница
уходит, а сайт выглядит как пустая оболочка будущего приложения.

## Входит
- `layouts/default.vue`: TopBar сверху, под ним контент на всю оставшуюся высоту экрана.
- `TopBar`: слева `ContactLinks`, справа `LocaleSwitch` и `ThemeToggle`. Под `InfoDialog`
  (шаг 1.3) оставляем место — справа, последним.
- `ContactLinks`: Telegram, LinkedIn, GitHub, Mail. Данные из `getCv`, иконки-кнопки с tooltip
  и `aria-label`.
- `ThemeToggle`: переключает светлую и тёмную тему. Иконка показывает тему, **в которую**
  переключит клик (луна в светлой, солнце в тёмной).
- `LocaleSwitch`: сегментированный переключатель `EN | RU`, активный язык подсвечен.
- Композабл `useCv()` — реактивное резюме текущей локали. Пригодится во всех следующих шагах.
- Иконки брендов (Telegram, GitHub, LinkedIn) — свои маленькие SVG-компоненты (почему — ниже).
- Демо-страница заменяется заглушкой: по центру одна строка «Здесь будет чат» через i18n.
- shadcn-компоненты: `tooltip`, `toggle-group`.

## Не входит
- `InfoDialog` → шаг 1.3
- Кнопка «Новый чат» → шаг 2.3
- Welcome-экран, чат → фаза 2
- Компонентные тесты (нужна отдельная инфраструктура: Nuxt-окружение для Vitest + happy-dom).
  Предлагаю добавить её, когда появится первая логика в компонентах (шаг 2.1). В этом шаге — ручная
  проверка в браузере по чек-листу.

## Ключевые решения и интерфейсы

### Иконки брендов
- В `@lucide/vue` бренд-иконок больше нет (GitHub, LinkedIn убраны из Lucide).
- В `simple-icons` есть Telegram и GitHub, но **нет LinkedIn**: его удалили по требованию правообладателя.
- Тянуть пакет на 3000+ иконок (или `@nuxt/icon` с Iconify) ради трёх штук — лишнее.

Поэтому три компонента с inline SVG. Пути для Telegram и GitHub берём из simple-icons (лицензия CC0),
для LinkedIn — простой знак «in». У всех иконок одинаковый интерфейс с Lucide: `size` через класс,
цвет через `currentColor`. Mail — из `@lucide/vue`.

### `useCv`
```ts
// app/composables/useCv.ts
import { getCv } from '#shared/cv'
import type { Locale } from '#shared/cv'

export function useCv() {
  const { locale } = useI18n()
  return computed(() => getCv(locale.value as Locale))
}
```
Автоимпорт композаблов Nuxt подхватит `useCv` во всех компонентах.

### ContactLinks
Ссылки — это `<a>`, а не кнопки с `window.open`: так работают средний клик, «копировать ссылку»
и читалки экрана. Рендерим через `Button` с `as-child`, чтобы получить стили кнопки на `<a>`.
- Telegram, LinkedIn, GitHub: `target="_blank" rel="noopener noreferrer"`.
- Mail: `mailto:` без `target`.
- Tooltip и `aria-label` — из i18n: «Telegram», «LinkedIn», «GitHub», «Написать на почту» / «Email me».

### ThemeToggle
```ts
const colorMode = useColorMode()
const isDark = computed(() => colorMode.value === 'dark')
function toggle() { colorMode.preference = isDark.value ? 'light' : 'dark' }
```
- Иконка внутри `<ClientOnly>`: при `preference: 'system'` сервер не знает тему, и без обёртки
  разметка сервера и клиента разойдётся. На время загрузки — пустая кнопка того же размера, без
  прыжка вёрстки.
- `aria-label` меняется: «Включить тёмную тему» / «Включить светлую тему».
- Вернуть режим «как в системе» из UI нельзя — по умолчанию он стоит, пока пользователь не нажмёт.
  Если нужно — см. вопрос 2.

### LocaleSwitch
`ToggleGroup` с `type="single"`, значения `en` / `ru`. Смена значения вызывает `setLocale(code)`
(переход на `/ru` или `/` без перезагрузки, cookie обновляется — это уже работает с шага 0.3).
Пустое значение не допускаем: повторный клик по активному языку ничего не меняет.

### Layout
```
┌────────────────────────────────────────────────┐
│ [tg] [in] [gh] [@]               [EN|RU] [☾] │  ← TopBar: высота 56px, sticky, граница снизу
├────────────────────────────────────────────────┤
│                                                │
│             <slot /> — flex-1                  │  ← в фазе 2 тут чат с прокруткой внутри
│                                                │
└────────────────────────────────────────────────┘
```
- Высота каркаса — `h-dvh` (а не `100vh`), чтобы на мобильных браузерах не прыгало при появлении
  адресной строки.
- Контент ограничен по ширине (`max-w-3xl`, по центру) — как в привычных чат-интерфейсах.
  TopBar — во всю ширину, внутри тот же контейнер.
- Все стили — классами в `<style scoped>` с `@apply` (правило из `CLAUDE.md`).

### Мобильная версия
На 375px помещаются все элементы: 4 иконки контактов + переключатель языка + тема (+ info в 1.3)
≈ 300px. Поэтому **контакты не сворачиваем в меню**, как планировалось в ARCHITECTURE: меню
добавляет лишний клик ради главного действия рекрутера — связаться. См. вопрос 1.

## Как проверить
- [ ] `pnpm lint`, `pnpm typecheck`, `pnpm test`, `pnpm build` — зелёные
- [ ] Все 4 ссылки ведут куда нужно, внешние открываются в новой вкладке, Mail открывает почтовый клиент
- [ ] Tooltip появляется при наведении и при фокусе с клавиатуры
- [ ] Tab проходит по всем элементам TopBar по порядку, фокус виден
- [ ] Тема переключается, иконка и `aria-label` меняются, выбор сохраняется после перезагрузки
- [ ] `EN | RU`: активный язык подсвечен, переключение меняет URL (`/` ↔ `/ru`) и тексты без перезагрузки
- [ ] Ширина 375px: всё в одну строку, без горизонтального скролла. Ширина 1440px: контент по центру
- [ ] Обе темы выглядят корректно (границы, hover, фокус)
- [ ] Нет hydration-warnings в консоли

## Открытые вопросы
1. **Контакты на мобильном** — оставить все 4 иконки на виду (предлагаю) или свернуть в меню, как
   было в ARCHITECTURE?
   - **Ответ:** все 4 иконки на виду.
2. **Тема** — простой переключатель светлая/тёмная (предлагаю) или меню из трёх пунктов
   «Светлая / Тёмная / Как в системе»?
   - **Ответ:** простой переключатель светлая/тёмная.
3. **Переключатель языка** — сегмент `EN | RU` (предлагаю, сразу видно оба варианта) или одна кнопка
   с другим языком, как на демо-странице?
   - **Ответ:** сегмент `EN | RU`.
