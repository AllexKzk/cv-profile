# 0.1. Скаффолд проекта

**Статус:** done
**Зависит от:** —
**Ветка:** `main` (первый коммит), дальше все шаги в `step/*`

## Цель
Пустой, но «правильно собранный» Nuxt 4 проект: строгий TypeScript, линтер, тесты и git.
Шаг нужен, чтобы все следующие начинались с зелёных `lint / typecheck / test / build`.

## Входит
- Инициализация Nuxt 4 (минимальный шаблон) в корне `cv-profile/`, менеджер пакетов **pnpm**.
- TypeScript strict + проверка типов через `vue-tsc` (`nuxt typecheck`).
- ESLint через модуль `@nuxt/eslint` (flat config).
- Vitest (окружение `node` для чистых функций; `@nuxt/test-utils` подключаем, но nuxt-окружение
  пока не используем) + один smoke-тест.
- Структура папок из ARCHITECTURE §4 и §6: только сами директории, где нужно (`app/`, `server/`, `shared/`).
- `app/app.vue` — одна строка «CV Agent — coming soon», без стилей.
- `.gitignore`, `.nvmrc` (Node 24), `.editorconfig`, `git init`, первый коммит (включая `docs/`).

## Не входит
- Tailwind, shadcn-vue, color-mode, шрифты → шаг 0.2
- i18n, `CLAUDE.md`, `.env.example`, деплой на Vercel → шаг 0.3
- Любые компоненты, страницы, серверные ручки.

## Ключевые решения и интерфейсы

Скрипты в `package.json`:
```json
{
  "dev": "nuxt dev",
  "build": "nuxt build",
  "preview": "nuxt preview",
  "postinstall": "nuxt prepare",
  "lint": "eslint .",
  "lint:fix": "eslint . --fix",
  "typecheck": "nuxt typecheck",
  "test": "vitest run",
  "test:watch": "vitest"
}
```

Версии на 2026-10-29: `nuxt 4.6.x`, `@nuxt/eslint 1.17.x`, `@nuxt/test-utils 4.3.x`,
`vitest 5.x`, `vue-tsc 3.3.x`.
**Риск:** последний `typescript` — 7.0 (нативный компилятор на Go). Исполнитель проверяет
peer-зависимости `vue-tsc` / Nuxt; если TS 7 не поддерживается — фиксирует последнюю 5.x и пишет
об этом в отчёте.

Форматирование: правила стиля ESLint (`@nuxt/eslint` → `features.stylistic: true`) **вместо
Prettier** — один инструмент, меньше конфликтов. См. открытый вопрос 1.

## Как проверить
- [ ] `pnpm install` без ошибок peer-зависимостей
- [ ] `pnpm dev` → `http://localhost:3000` показывает заглушку, в консоли нет warnings
- [ ] `pnpm lint`, `pnpm typecheck`, `pnpm test`, `pnpm build` — все зелёные
- [ ] `git log` — один коммит, `node_modules`, `.nuxt`, `.output`, `.env` в `.gitignore`
