# 0.2. UI-фундамент: Tailwind v4, shadcn-vue, тема, шрифты

**Статус:** done
**Зависит от:** 0.1
**Ветка:** `step/0.2-ui-foundation`

## Цель
Подключить дизайн-систему: Tailwind v4, shadcn-vue с токенами светлой и тёмной темы,
переключение темы через `@nuxtjs/color-mode` и шрифты. После шага любой компонент можно
стилизовать токенами (`bg-background`, `text-muted-foreground`, …) и добавлять shadcn-компоненты
одной командой.

## Входит
- **Tailwind v4** через Vite-плагин `@tailwindcss/vite`.
- **shadcn-vue:** модуль `shadcn-nuxt`, `components.json`, утилита `cn()`, CSS-токены для light и dark.
- Из компонентов добавляем **только `button`** — чтобы проверить связку. Остальные добавляются
  в тех шагах, где они реально нужны: так диффы меньше, и видно, откуда пришёл каждый компонент.
- **`@nuxtjs/color-mode`:** класс `.dark` на `<html>`, по умолчанию берётся системная тема, выбор
  запоминается.
- **`@nuxt/fonts`:** шрифты скачиваются при сборке и раздаются с нашего домена, без запросов к Google
  в рантайме.
- **`lucide-vue-next`** — иконки, которые использует shadcn-vue.
- **Временная демо-страница** в `app/app.vue`: заголовок, абзац с `text-muted-foreground`, кнопки
  в вариантах `default` / `secondary` / `outline` / `ghost` и кнопка смены темы. Её заменит каркас
  в шаге 1.2.

## Не входит
- Настоящий `ThemeToggle`, TopBar, layout → шаг 1.2
- i18n, `CLAUDE.md`, деплой → шаг 0.3
- Другие shadcn-компоненты, кастомная палитра (бренд-цвет) — обсудим, когда появятся реальные экраны.

## Ключевые решения и интерфейсы

**Почему `@tailwindcss/vite`, а не `@nuxtjs/tailwindcss`.** Модуль `@nuxtjs/tailwindcss` (6.x)
сделан под Tailwind v3. Для v4 официальный путь — Vite-плагин и конфигурация прямо в CSS
(`@theme`), без `tailwind.config.js`.

**Настройки в `nuxt.config.ts`:**
```ts
shadcn: {
  prefix: '',                          // <Button>, а не <UiButton>
  componentDir: './app/components/ui',
},
colorMode: {
  classSuffix: '',                     // класс `.dark`, а не `.dark-mode` — так ждёт shadcn
  preference: 'system',
  fallback: 'light',
  storageKey: 'cv-color-mode',
},
fonts: {
  defaults: { weights: [400, 500, 600, 700] },
},
```

**Как устроены токены.** shadcn-vue кладёт цвета CSS-переменными в формате `oklch` в `:root`
(светлая тема) и `.dark` (тёмная), а `@theme inline` превращает их в утилиты Tailwind
(`--color-background: var(--background)` → `bg-background`). Компоненты ссылаются только
на токены, поэтому смена темы — это просто класс `.dark` на `<html>`, без перерисовки.

**Шрифты.** В CSS прописываем `--font-sans` и `--font-mono`, а `@nuxt/fonts` сам находит
семейства в CSS и подключает их. Выбрано **Roboto / Roboto Mono** (вопрос 2).

**Версии на 2026-10-29:** `tailwindcss` / `@tailwindcss/vite` 4.3.x, `shadcn-vue` / `shadcn-nuxt`
2.9.x, `reka-ui` 2.11.x, `@nuxtjs/color-mode` 4.1.x, `@nuxt/fonts` 1.2.x,
`lucide-vue-next` 1.0.x, `tw-animate-css` 1.4.x.

**Порядок для исполнителя:** поставить Tailwind и модули → `pnpm dlx shadcn-vue@2.9 init`
(базовый цвет — по ответу на вопрос 1) → `pnpm dlx shadcn-vue@2.9 add button` → проверить,
что CLI ничего не записал за пределами файлов из таблицы. Если записал — убрать или описать в отчёте.

## Как проверить
- [ ] `pnpm lint`, `pnpm typecheck`, `pnpm test`, `pnpm build` — зелёные
- [ ] Демо-страница: кнопки во всех вариантах, шрифт Roboto (DevTools → Computed → font-family)
- [ ] Смена темы: цвета фона, текста и кнопок меняются, после перезагрузки тема сохраняется
- [ ] Системная тема: при `preference: 'system'` и тёмной ОС страница сразу тёмная, **без вспышки
  светлой темы** при загрузке (color-mode ставит класс скриптом в `<head>` до гидратации)
- [ ] Нет hydration-warnings в консоли
- [ ] В Network нет запросов к `fonts.googleapis.com` / `fonts.gstatic.com` — шрифты с localhost

## Открытые вопросы
1. **Базовая палитра shadcn:** `neutral` (чистый серый, предлагаю), `zinc` (чуть холоднее), `stone`
   (теплее)? Акцентный цвет подберём позже, при работе над экранами.
   - **Ответ:** `zinc`.
2. **Шрифт:** Geist + Geist Mono (современный, хорошо смотрится в чатах), Inter, или свой вариант?
   Важно: нужна кириллица. Исполнитель проверяет её на демо-странице строкой на русском; если
   у выбранного шрифта кириллицы нет — останавливается и спрашивает.
   - **Ответ:** Roboto (+ Roboto Mono для моноширинного).
